# Heart-Disease-Exploratory-Data-Analysis
"CardioRisk-AI: An end-to-end machine learning pipeline for early cardiovascular disease prediction, featuring exploratory data analysis, clinical interpretability, and predictive modeling using Python."
About the Project
CardioRisk-AI is a data science and machine learning project focused on cardiovascular health. The project aims to analyze clinical heart datasets, uncover hidden risk patterns, and build predictive models to assist in early cardiovascular disease detection and support data-driven clinical decision-making.

Key Features
Exploratory Data Analysis (EDA): Deep dive into patient clinical features, correlations, and key health indicators associated with heart disease.

Data Preprocessing: Robust cleaning, handling missing values, feature scaling, and data preparation for machine learning.

Predictive Modeling: Training and evaluating machine learning models (such as Random Forest and Logistic Regression) to predict cardiovascular risk.

Model Evaluation: Assessing performance using key metrics like Accuracy, Precision, Recall, and ROC-AUC.

Tech Stack
Language: Python

Libraries: Scikit-Learn, Pandas, NumPy, Matplotlib, Seaborn

Environment: Jupyter Notebooks / Google Colab
